## Selected Projects

### [yt-vocab-studio](https://github.com/MuhammedCanCeylan/yt-vocab-studio)

An end-to-end language-learning ecosystem built around YouTube content.

The platform extracts vocabulary from video transcripts and transforms it into interactive learning experiences including reading assistance, SRS-based study modes, and game-based exercises.

**Stack:** `Python` `Flask` `JavaScript` `WebGL`

---

### [quizwet-clone-pro](https://github.com/MuhammedCanCeylan/quizwet-clone-pro)

A fully offline desktop learning platform designed around vocabulary memorization and interactive learning.

Combines flashcard-based learning with a space-themed arcade experience in a native cross-platform application.

**Stack:** `Tauri` `React` `TypeScript` `Rust`

---

### [MotoWeather](https://github.com/MuhammedCanCeylan/MotoWeather)

A native Android application designed specifically for motorcyclists.

Provides real-time weather intelligence, rider-focused risk analysis, personalized rider profiles, and a custom astronomy-inspired interface.

**Stack:** `Kotlin` `Android` `API Integration`

### [ShadowTrade](https://github.com/MuhammedCanCeylan/ShadowTrade-Anonim-Pazar-Yeri)

A privacy-focused anonymous marketplace concept built around direct cryptocurrency transactions without traditional intermediaries.

**Stack:** `PHP` `MySQL` `Backend`
